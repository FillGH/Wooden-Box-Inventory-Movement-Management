# Wooden Box Inventory & Movement Management

> **Project stage: DEFINE / DESIGN PREPARATION** · **Baseline: v0.1 draft** · **Updated: 2026-10-28**

เครื่องมือสำหรับบันทึกการรับเข้า ติดตามสต๊อก ตำแหน่งจัดเก็บ และการเคลื่อนย้ายชิ้นส่วนลังไม้บรรจุกระจก ภายในหน่วยงาน Cutting & Packing โดยเน้นการใช้งานบนมือถือและกรอกข้อมูลให้สั้นที่สุด

**เป้าหมาย:** คนรับของบันทึกข้อมูลที่จุดเกิดเหตุครั้งเดียว แล้วผู้ที่ต้องค้นหา ย้าย หรือเบิกใช้สามารถตรวจสอบข้อมูลล่าสุดจากแหล่งเดียวได้ โดยไม่ต้องผ่านคนกลางหรือเดินนับซ้ำเป็นประจำ

## ขอบเขตที่ยืนยันแล้ว

- รับลังไม้เข้าพร้อมรายละเอียดสินค้า เอกสารอ้างอิง จำนวนชิ้นส่วน ผู้รับ และพื้นที่รับลง
- ติดตาม Top / Bottom / Side แยกจำนวน รองรับการส่งไม่ครบหรือส่งหลายรอบ
- มี movement transactions ที่เรียบง่าย เช่น รับเข้า ย้ายที่ เบิกใช้ และบันทึกชำรุด
- ค้นหาคงเหลือและตำแหน่งจัดเก็บ
- Export ข้อมูลเพื่อนำไปใช้งานกับ Excel
- ผู้เกี่ยวข้องในกระบวนการระยะแรก: คนรับลัง Supplier ผู้ส่งของ หัวหน้างาน และพนักงานขับ Forklift
- ถ้าสร้าง Web App จะใช้ Cloudflare เป็นแพลตฟอร์มเป้าหมาย (รายละเอียดสถาปัตยกรรมยังไม่ยืนยัน)

## ขอบเขตที่ไม่ทำ

- ไม่สแกน QR Code / Barcode
- ไม่ดึง/นำเข้าหรือจัดการ Production Plan ของ PPIC
- ไม่ดึง/นำเข้าหรือจัดการ PO และกระบวนการ Purchasing
- ไม่เชื่อม ERP หรือสร้างระบบตรวจความพร้อมตามแผนผลิตอัตโนมัติในระยะนี้
- ไม่เริ่มพัฒนาจนกว่าข้อกำหนดและ UI/UX หลักจะได้รับการยืนยัน

**หมายเหตุ:** เก็บ **PO Number เฉพาะ 4 ตัวท้าย** เป็นข้อมูลอ้างอิงตอนรับของ ไม่ถือว่าเป็นโมดูล Purchasing

## สถานะปัจจุบัน

ยังไม่มีแอป ฐานข้อมูล ระบบ login หรือการ deploy ใด ๆ ใน repository นี้ รายการในเอกสารที่ระบุว่า **เสนอ / Draft / TBD** ยังไม่ใช่ข้อกำหนดที่อนุมัติแล้ว

ขั้นตอนถัดไป: ตอบคำถามสำคัญ → ออกแบบ user flows → ทดสอบต้นแบบบนมือถือด้วยข้อมูลจำลอง → ยืนยัน Ready to Build → เริ่ม implementation

## ข้อมูลและความปลอดภัย

Repository นี้เป็น **Public** เอกสารจึงใช้ข้อมูลทั่วไปหรือตัวอย่างสมมติเท่านั้น **ห้าม commit** ใบส่งของจริง, Invoice/PO จริง, ข้อมูลลูกค้า/ราคาสั่งซื้อ, ข้อมูลพนักงานส่วนบุคคล, credentials, API keys, tokens หรือข้อมูลภายในโรงงานที่ไม่ได้อนุมัติให้เผยแพร่

การนำระบบไปใช้จริง รวมถึง Cloudflare, BYOD, สิทธิ์ผู้ใช้, การสำรองข้อมูล และการเก็บข้อมูลบริษัทต้องผ่านการพิจารณานโยบาย IT ที่เกี่ยวข้องก่อน
